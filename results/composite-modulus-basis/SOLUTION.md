# 合数模线性基：带时间标记的 p-进阶梯表

## 结论

可以做到接近普通区间线性基的复杂度。设已知

\[
m=\prod_{s=1}^{w}p_s^{k_s},\qquad K=\sum_s k_s.
\]

本目录给出了构造性算法、证明和 Python 标准库实现 `solver.py`：

| 模式 | 预处理的主要模运算量 | 单次查询的主要模运算量 | 基结构空间 |
|---|---:|---:|---:|
| 单个素数幂，按右端点离线 | \(O(nd^2k)\) | \(O(d^2)\) | \(O(d^2k)\) |
| 一般整数模数，按右端点离线 | \(O(nd^2K)\) | \(O(wd^2)\) | \(O(d^2K)\) |
| 保存所有前缀，在线回答任意历史区间 | 同上 | 同上 | \(O(nd^2K)\) |

特别地，`m=p²` 只需每列两个槽位，与普通域上线性基有相同的主要渐近复杂度。`k=1` 时算法退化成普通的带最新位置的线性基。

上表统计模加、模乘等主体工作；堆比较、p-进赋值计算、单位求逆、整数位复杂度及分解模数的成本在后文单独列出。没有把大整数因数分解视为免费操作。

## 1. 直接照搬普通线性基会错在哪里

### 非单位主元的倍数能产生新的后续主元

在模 4 下，只有一个向量

\[
a=(2,1),\qquad 2a=(0,2).
\]

如果只在第一列保留 `a`，查询 `(0,2)` 时找不到第二列主元，就会错误地回答不能表示。一般模 `p²` 的 `(p,1)` 同样如此。

### 一个位置不能仅保留最新的原向量

模 4、一维序列 `a₁=1, a₂=2`：整个区间能表示 1，后缀 `[2,2]` 只能表示 0 和 2。用最新的 2 完全替换 1 会丢失旧区间的信息，只保留 1 又不能表达新后缀。

模 `p^k` 的一维序列

\[
1,p,p^2,\ldots,p^{k-1}
\]

有 `k` 个不同的非零后缀理想。这说明普通域上“每列一个带位置的原向量”并不足够；本算法每列使用 `k` 个槽位。这里不声称一般数据结构必须占用 `k` 个完整向量。

### 消元后的时间标记必须保守

若用较新的行消去较旧的行，余行仍使用较旧的时间。不能因为参加过较新向量的消元，就将余行标为较新位置。

例如模 4 下 `(1,0), (1,1)` 的差为 `(0,1)`，但第二个向量单独不能表示这个差。

## 2. 素数幂上的表和查询

以下令 `R=Z/p^kZ`，所有坐标规范化到 `[0,p^k)`。

非零行 `b` 的首项位置定义为

\[
\operatorname{lead}(b)=(j,v_p(b_j)),
\]

其中 `j` 是第一个非零坐标，位置按先 `j` 后赋值的字典序排列。乘以 `p` 后，非零行的首项位置严格增大，或者整行变成零。

维护 `B[j][v]`，共 `dk` 个槽位。非空槽包含：

- 向量 `b`：前 `j` 个坐标为零，主元归一化为 `b_j=p^v`；
- 时间 `t`：这行可以由当前前缀中位置至少为 `t` 的原向量表示；
- 幂层 `e`：这行来自原向量 `a_t` 的 `p^e` 倍。

**`e` 与主元赋值 `v` 是不同的量。** 消元到后面的列后，主元赋值可以改变，幂层仍然保留。

归一化合法：若 `b_j=p^v u`，则 `u` 与 `p` 互素，可以求 `u` 在模 `p^k` 下的逆元，再将整行乘以该逆元。没有求非单位 `p^v` 的逆元。

处理完前缀 `r` 后，区间 `[l,r]` 只使用时间 `t≥l` 的槽位。查询过程是：

```text
for j = 0 .. d-1:
    if x[j] == 0: continue
    v = valuation_p(x[j])
    b = B[j][v]
    if b 不存在，或 b.time < l: return NO
    c = x[j] / p^v                 # 整数除法，不是环中的逆元
    x = x - c*b                   # 模 p^k，整个第 j 坐标变成零
return YES
```

一次成功消元清空整个坐标，因此至多 `d` 次向量操作，每次 `O(d)`。查询不会修改表。

## 3. p-数字基及其基本性质

这里的“基”指 **p-数字基**：一组首项位置互异的行，使子模中每个元素都可唯一写成

\[
\sum_b c_b b,\qquad c_b\in\{0,1,\ldots,p-1\}.
\]

这不是通常的自由模基，也不要求不同的行在 `R` 上线性无关。

**性质一：不同数字组合一定不同。** 两个组合相减，取非零系数对应的最小首项位置。该系数在 `-(p-1),...,p-1` 中且非零，因此不是 `p` 的倍数；首项处不可能被赋值更大的项抵消。

**性质二：成员查询正确。** 若 `x` 在子模中，它的数字展开的首个非零项与 `x` 有相同的首项位置，所以必定有对应槽位。减去主元的任意环倍数后仍在子模中，可以继续消元。反之，成功消元本身就是一份线性表示的存在性证明。

**性质三：部分消元给出商群中固有的首项位置。** 对子模 `H` 的数字基做消元，直到首次遇到缺失槽位，得到非零余行 `b`。其首项位置只取决于陪集 `x+H`：若同一陪集的两个这类余行有不同首项，二者之差属于 `H`，但其首项又是 `H` 缺失的槽位，与性质二矛盾。

如果陪集非零，称这个位置为它的首项。将陪集乘以 `p`，首项严格增大，或陪集归零：先将余行乘 `p`，再对 `H` 消元即可。乘单位不改变陪集的首项。

### 往已有子模中加入一个向量

设 `a+H` 在加法商群中的阶是 `p^h`，`0≤h≤k`。那么 `p^e a+H` 在 `e<h` 时非零，并有严格递增的首项；在 `e≥h` 时为零。

因此，对 `a,pa,...,p^(k-1)a` 依次消元，恰好留下 `h` 个首项互异的新行。它们可以归一化为

\[
b_e\equiv u_e p^e a\pmod H,\qquad p\nmid u_e,\quad 0\le e<h.
\]

这些行的数字组合遍历循环商群 `(H+Ra)/H` 的全部 `p^h` 个元素。可逐个确定 p-进数字：第 `e` 层的系数单位 `u_e` 总能匹配该位，所产生的进位留给后面的层。因此它们与 `H` 的数字基合起来，正是 `H+Ra` 的数字基。

这也说明：同一原向量的不同保留幂层，在对较新子模消元后，不会争用同一个槽位。

## 4. 快速带时间插入

一个便于理解但较慢的构造是：每个前缀都按 `a_r,a_(r-1),...,a_1` 的顺序重建，每个原向量加入全部 `p` 幂倍数。上一节已经证明了它会对每个后缀产生数字基。

快速算法保留这些结果，只处理新向量引起的主元替换。

插入位置 `r` 时，先把不为零的

\[
(a_r,r,0),(pa_r,r,1),\ldots,(p^{k-1}a_r,r,k-1)
\]

放进优先队列。队列按时间从大到小处理，同时间按幂层从小到大处理。至多有 `k` 个待处理行。

```text
while 队列非空:
    取时间最新的 (a,t,e,start)
    从 start 起寻找 a 的非零坐标 j
    v = valuation_p(a[j])

    如果 B[j][v] 为空:
        归一化 a，存为 (a,t,e)，结束这条处理链

    否则，如果槽位中的 b.time > t:
        a -= (a[j]/p^v)*b
        继续下一列

    否则（a 较新）:
        归一化 a，替换槽位中的旧行 b
        b -= (b[j]/p^v)*a
        把非零余行 b 以旧时间、旧幂层和 start=j+1 放回队列
        结束当前处理
```

同时间碰撞不会发生，下节证明这一点，代码也保留断言。**被替换的旧行必须回到优先队列，保证全部较新时间先处理完成。** 本解答不将“立即一路处理被换出的旧行”的实验版本作为已证明算法交付。

替换不破坏时间语义：较旧的行减去较新的行，仍然只用得到时间不早于自己的原向量。归一化只乘单位，幂层仍保持不变。

## 5. 时间标记算法的正确性证明

令

\[
H_{t+1}^{(r)}=\langle a_{t+1},...,a_r\rangle_R.
\]

完成前缀 `r` 后，维护以下更强不变量：

1. 对每个左端点 `l`，时间至少为 `l` 的行是 `[l,r]` 生成子模的 p-数字基。
2. 设 `a_t` 在商群 `R^d/H_(t+1)^(r)` 中的阶为 `p^(h_t)`。时间恰为 `t` 的行有且仅有幂层 `e=0,...,h_t-1`，并满足
   \[
   b_{t,e}\equiv u_{t,e}p^e a_t\pmod{H_{t+1}^{(r)}},\qquad p\nmid u_{t,e}.
   \]

空表满足不变量。以下证明一次插入后仍成立。

**第一步：每条旧行保持其商群身份。** 新加入的向量只会扩大较新子模。旧行减去较新行、再乘单位后，仍满足上述同余式。新向量的初始幂链显然满足它。一次替换只转移或消去一条旧行，不会复制同一 `(时间,幂层)`。

**第二步：按时间从大到小归纳。** 队列优先处理较新的行；一次替换只会重新排入较旧的行。考虑处理时间 `t` 时，所有更高时间已经稳定，并按归纳假设形成了新的子模 `H=⟨a_(t+1),...,a_r⟩` 的数字基。

在旧前缀中时间 `t` 有 `h_old` 个幂层；新的商群阶指数 `h_new≤h_old`，因为 `H` 只会扩大。需要保留的 `e<h_new` 都还存在于表中或队列中：只可能丢弃对较新行消元后为零的行，而这样的行必有 `e≥h_new`。

已经留在表里的时间 `t` 行，其首项槽位没有较新行，因而是对 `H` 部分消元后的余行。排队的时间 `t` 行也会先用较新行消元。

- 若 `e≥h_new`，其陪集为零，必被较新基消为零。
- 若 `e<h_new`，会在一个 `H` 缺失的槽位停止，并保留下来；那里若有较旧行，就替换并重新排队较旧行。
- 两个不同幂层不可能同槽：上一节的商群首项性质说明，它们的首项严格递增。相同幂层又从未被复制。因此不会发生同时间碰撞。

于是时间 `t` 最终恰好留下所需的 `h_new` 层。由循环商群引理，将它们与较新基合并，就得到 `⟨a_t,...,a_r⟩` 的数字基。

对全部时间向下归纳，两个不变量成立。只保留时间至少为查询左端点的行，因此正确表示对应区间生成子模。

## 6. 复杂度与在线版本

### 单次插入为什么只有 k 条消元链

开始只有至多 `k` 个任务。任务碰到空槽即终止；替换时，当前任务只换成一个旧行余量，没有分叉。每次非零坐标的消元都会清空整列；重新排队从下一列开始。因此可以把工作追踪成至多 `k` 条链，每条访问至多 `d` 列。

每次访问进行至多常数次长度 `d` 的向量操作，故单次插入主体工作 `O(kd²)`。这与“每次替换后再额外生成一个 p 倍行”的闭包算法不同；后者会分叉，不能使用这个复杂度证明。

每次插入还包括：

- `O(kd log(k+1))` 次优先队列比较；队列大小始终不超过 `k`。
- 至多 `kd` 次单位求逆。若一次求逆成本为 `I(p^k)`，额外计入 `O(kd I(p^k))`。
- `O(kd)` 次 p-进赋值计算。实现对 `p=2` 用末尾零位；对其他 `p` 在预存的 `p^v` 上二分，使用 `O(log(k+1))` 次整除性测试。

查询有至多 `d` 次赋值计算，不需要求逆。所以更细的、将求逆单列的单位成本表达是

\[
O\!\left(nkd(d+\log(k+1)+I(p^k))+qd(d+\log(k+1))\right).
\]

涉及任意精度整数时，还须乘入相应长度整数的运算成本。这是模运算量分析，不是声称独立于 `log m` 的位复杂度。

### 离线

将查询按右端点分桶，扫描 `r=1..n`，插入 `a_r` 后回答该桶中的查询。分桶 `O(n+q)`；基结构内存 `O(d²k)`，另计输入、查询、桶及输出所占空间。

### 在线查询与在线追加

每次处理完前缀，保存 `dk` 个槽位的指针快照。向量行和槽位记录不可变，快照只复制引用。一次插入产生 `O(kd)` 个新槽位记录，每个有长度 `d` 的行。

- 所有前缀的总空间 `O(nd²k)`。
- 快照复制总时间 `O(ndk)`，不超过主体预处理量。
- 查询 `[l,r]` 直接访问前缀 `r` 的快照，仍为 `O(d²)` 主体模运算。

因此可以先读完整序列后按任意顺序回答查询，也可以不断追加向量并查询任意已经存在的历史区间。`RangeBasis` 实现了后者。这里不支持修改中间位置或删除向量。

如果不想复制所有槽位指针，可以每槽记录变更历史，查询时按右端点二分，或用持久化数组；会增加查询访问成本，并不是达到上述空间界所必需的。

## 7. 任意整数模数：CRT

分别在各 `Z/p_s^(k_s)Z` 上运行算法；一个查询当且仅当所有分量都成功。

必要性显然。充分性也需要说明：每个素数幂分量可以得到一组不同的系数 `λ_i^(s)`，但可以对每一个下标 `i` 分别使用中国剩余定理，将它们合成同一个模 `m` 的系数 `λ_i`。所以不要求各分量先找出相同的整数系数。

只判断成员关系，不需要显式求 CRT 合成值。`m=1` 是零环，任何目标向量都等价于零，所有合法区间查询回答 `YES`。

**因数分解成本。** 理论界从已知素因子分解开始。参考实现默认使用试除法，最坏 `O(sqrt(m))` 次试除，只适合作为验证实现或模数较小时使用。已知分解时，可以提供 `--factors 2:2,3:1`；代码检查乘积、正性与不同底数，但调用者必须保证提供的底数确实为素数。本题算法没有解决大整数因数分解问题。

## 8. Smith / Hermite 标准形的关系

单个区间的生成子模成员关系等价于整数格成员关系

\[
x\in A\mathbb Z^{r-l+1}+m\mathbb Z^d.
\]

因此可以用 Hermite 标准形处理格基，也可以对相应矩阵求 Smith 标准形。成员查询需要相应的基变换，只有 Smith 对角不变量通常不够判断指定的 `x`。

本算法没有对每个区间重复求标准形。它维护的是同时适配全部后缀的数字基，依靠时间标记和每个新原向量只增加一个循环商群这一事实快速更新。

附带结果：若某个后缀中可用槽位数量为 `s`，则它在模 `p^k` 上的生成子模恰有 `p^s` 个元素。一般 `m` 的子模大小是各分量大小之积。测试也使用这一性质独立核对槽位数量。

## 9. 推广到任意有限交换环

有限交换环未必是素数幂链环，不能直接把其元素当成具有单一 p-进赋值的整数。例如

\[
\mathbb F_2[\epsilon,\eta]/(\epsilon^2,\epsilon\eta,\eta^2)
\]

的极大理想有两个独立方向。不过，可以通过加法群作一个通用归约。

假定环的加法群分解、坐标转换和乘法已经给定。对其某个 p-主分量，写成

\[
(R_p,+)\cong\bigoplus_{j=1}^{s_p}\mathbb Z/p^{e_j}\mathbb Z,
\quad E_p=\max_j e_j.
\]

选取这些循环因子的加法生成元 `b₁,...,b_s`。对每个原向量 `a_i`，生成同一块中的 `s_p` 个向量

\[
b_1 a_i,\ldots,b_{s_p}a_i.
\]

原因是任意环系数都能写成 `Σ_j z_j b_j`，所以环线性组合恰好等于这些乘积向量的整数线性组合。

将每个加法坐标 `z mod p^(e_j)` 映入 `Z/p^(E_p)Z` 的坐标

\[
z\longmapsto p^{E_p-e_j}z.
\]

这是单射加法同态。`d` 维环向量因此嵌入模 `p^(E_p)` 的 `d s_p` 维整数向量，目标向量也做同样转换。不同 p-主分量的乘积为零，可以分别处理。

每个乘积向量使用独立的虚拟时间戳：原区间 `[l,r]` 映射为

\[
[(l-1)s_p+1,\;r s_p].
\]

不能直接将一块内多个不同生成元塞入同一个时间戳，否则破坏本算法“每个时间对应一个循环商群”的证明。

每个 p-主分量共有 `ns_p` 个向量，维度 `ds_p`，指数 `E_p`，故主体预处理量

\[
O(nd^2 E_p s_p^3),
\]

单次查询 `O(d²s_p²)`，再对不同 `p` 求和，并另计环表示转换和乘法成本。

这给出了任意有限交换环的算法，但当加法秩 `s_p` 较大时，复杂度不再是整数模数情形的简单常数倍。此处不声称未知表示下的环分解和乘法可以免费获得，也不声称该一般环界最优。

## 10. 运行与验证

输入格式由本目录为验证目的约定：

```text
n d m q
a_1 的 d 个坐标
...
a_n 的 d 个坐标
l r x 的 d 个坐标          # 共 q 行
```

```sh
python3 solver.py < example.in
python3 solver.py --online < example.in
python3 solver.py --factors 2:2 < example.in
python3 test_solver.py
python3 benchmark.py
```

输出每个查询一行 `YES` 或 `NO`。`example.out` 是样例答案。

- `solver.py`：交付实现；离线查询、追加与历史查询、子模大小。
- `test_solver.py`：独立枚举系数生成子模，核对所有目标；结构化随机测试；一般环归约测试。
- `experiment.py`：早期的显式 p 倍闭包原型，作为额外对照。
- `fast_experiment.py`：快速优先队列版本的探索性验证。
- `benchmark.py` / `benchmark_results.txt`：固定种子的性能样例与实际输出。
- `PROGRESS.md`：研究经过、已验证结果和界限。

这里的证明与代码均在本目录独立完成；没有读取其他题目目录或访问 README 链接中的外部文章。实际跑出的测试计数与用时记录在 `PROGRESS.md`。
