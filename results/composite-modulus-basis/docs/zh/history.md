# 整理与验证记录

[English](../en/history.md) · [当前说明](../../README.md)

这里记录演变过程；当前规格以 [ARTICLE.md](../../paper/main-zh.tex)、[SOLUTION.md](extensions.md)
及 [LEAN_VERIFICATION.md](formalization.md) 为准。实测输出独立保存，避免在历史记录里重复维护数字。

## 2026-09-11：原型与反例

- 研究素数幂上的区间生成子模成员查询。
- 用显式加入 p 倍行的闭包原型验证成员关系。
- 确认两个直接推广的错误：模 4 下 `(2,1)` 的倍数 `(0,2)` 需要后续主元；序列 `1,2` 不能只保留最新原向量。
- 探索“旧余行立即继续处理”的变体，但它不作为正式保证的算法。

## 2026-09-12：算法与程序

- 确立按时间优先处理、替换时重新排入旧余行的算法。
- 给出循环商群幂层证明和不分叉链复杂度界，完成 Python 追加、历史查询与离线接口。
- 加入系数枚举、元数据、显式闭包对照和一般有限环归约测试。

## 2026-09-14：核心形式化复核

- 复核完整的 Mathlib 证明链，包括数字基、同时间碰撞排除、插入终止性、后缀查询和 CRT。
- 将初始幂链生成额度补入精确计数；正维度时得到 `3nkd²` 个主体坐标更新的额度。
- 区分数学算法操作计数、标量子程序成本和 Python 源码精化范围。

## 2026-09-15：公开仓库整理

- 在 `lean/` 收录固定工具链和依赖提交的一般性证明；可选有限模型单列为 `LeanRegression`。
- 增加 `verify_lean.py`，构建证明并检查八个核心定理的公理白名单。
- 将历史原型收纳到 `experiments/`，正式程序仍以 `solver.py` 为入口。
- 预存幂改为逐次相乘，省去插入时未使用的最后一层计算；增加列访问和初始行遍历计数。
- CLI 的非整数输入改为清晰的参数错误；保留底数素性由调用者保证的明确契约。
- 新增 `tests/` 中的独立整数格 oracle、可逆坐标变换构造和一维 gcd 测试。
- 测试扩大到 31 位质数、深幂层及 120 位 CRT 模数；保留小参数穷举，并同时检验 YES、NO、历史版本和操作上界。
- 性能样例覆盖小合数、大素数幂和大 CRT 模数，并进行独立格成员抽查。
- 中文核心文章为主，同步英文使用说明、证明、Lean 范围、测试及整理记录。
- 增加 Python 3.10/3.14 与 Lean 的 GitHub Actions 配置；远程运行结果以 GitHub 实际执行为准。

实测报告：[程序测试](../../artifacts/tests.txt)、[Lean 检查](../../artifacts/lean.txt)、[性能样例](../../artifacts/benchmarks.txt)。
